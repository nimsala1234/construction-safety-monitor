# Construction Safety Monitor

A computer vision project for detecting workers, recognizing PPE, and identifying safety violations on construction sites.

## Planned Features
- Worker detection
- Helmet detection
- High-visibility vest detection
- PPE compliance checking
- Safe/unsafe scene classification

## Project Structure
- `data/` for dataset files
- `src/` for source code
- `notebooks/` for Colab notebooks
- `docs/` for project documentation
- `results/` for outputs and evaluation
